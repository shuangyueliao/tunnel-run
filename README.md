# Tunnel Run · 霓虹隧道跑酷

Free single-file HTML5 arcade game. Steer a glowing orb down an endless
neon tunnel — thread the shifting gates, collect energy orbs, and grab
shields to survive one crash. One HTML file, zero assets.

**Play:** https://shuangyueliao.github.io/tunnel-run/

- Drag / touch / arrow keys / A-D, procedural WebAudio sounds
- Neon visuals, speed lines, particle explosions — no dependencies
